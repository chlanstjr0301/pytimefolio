\claim{\secnum{2}{sec:layers}\quad Five protocol layers, each measured live, determine the wrapper's parameters}

\lead{Every timeout, interval and size the wrapper uses is tied to a measurement or a stated rule.} The measurements were made against the live server between 05:38 and 10:34 KST on 24 Nov 2026; the exceptions are the 3\,s poll interval, taken from a browser recording of 28 Oct 2026, and the daily cap, taken from the organiser's e-mail [5]. Where a limit is measured or stated, the wrapper sets its own parameter with a margin inside it (Section~\ref{sec:design}). With no documentation from the organiser, the alternative to measuring is guessing, and Section~\ref{sec:queries} shows that the server answers a wrong guess with HTTP 200. Each subsection measures one layer and ends with the parameters it sets: \ref{sec:transport} the transport (a reused connection, 16.0\ms{} against 106.5\ms), \ref{sec:auth} authentication (a 900\,s access token and a 7-day cookie jar), \ref{sec:queries} queries (dates taken from the server), \ref{sec:feed} the live feed (a 3\,s poll and deltas) and \ref{sec:orders} orders (placement, confirmation and size). The server can change these behaviours at any time; Section~\ref{sec:validity} lists the ones the wrapper checks before each order.
